## 🌟 Project Overview

Welcome to the **JavaScript Basics Training Project**! 🎉  
This project helps you understand and apply **core JavaScript concepts** step-by-step.

### Topics Covered:
- Variables, Data Types, and Operators  
- Control Structures (`if`, `for`, `while`, `switch`)  
- Functions and Scope  
- Arrays & Objects  
- DOM Manipulation  
- Events and Listeners  
- ES6 Features  
- Debugging & Console Tools  

> 🎯 **Goal:** Build confidence in writing clean, efficient JavaScript and prepare for frameworks like React or Angular.
